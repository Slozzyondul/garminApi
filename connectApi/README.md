# Garmin Data Explorer

A Flask-based web application for accessing and analyzing Garmin device data.

## Features

- ✅ Authenticate with Garmin Connect
- ✅ View activities and statistics
- ✅ Download activity data (FIT, GPX, TCX)
- ✅ Parse and analyze FIT files
- ✅ Visualize heart rate zones
- ✅ Device information display
- ✅ Sleep and stress data analysis
